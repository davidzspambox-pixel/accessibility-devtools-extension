Privacy Policy

Accessibility DevTools • Effective February 2026

This Privacy Policy describes how we handle information in the Accessibility DevTools Chrome Extension. We believe that developer tools should be transparent, lightweight, and respect your privacy.

Core Privacy Principle

This extension is built to run entirely in your local browser environment. We do not collect, store, or transmit any data to external servers. There is no backend, no tracking, and no analytics.

Data Access & Usage

  • Website Content Accessed locally to analyze DOM elements for ARIA compliance and accessibility standards. This data never leaves your browser.
  • User Activity Monitored within the active tab to help you debug event listeners and user interactions in real-time.
  • Local Storage Any settings you toggle are stored locally in your browser's chrome.storage and are not synced to any cloud service.

No Third-Party Sharing

Because we do not collect any data, we have nothing to share, sell, or trade with third parties. Your code and your browsing habits remain yours alone.

Contact & Support

If you have questions about the extension or the way it handles data, please open an issue on the official GitHub repository or contact us via the Chrome Web Store support tab.
